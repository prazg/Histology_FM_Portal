Histology FM Portal

Open-weight histology foundation models on one bench.

Pick a model, give it tiles or a whole slide, and get the output its training was built for: embeddings and cluster maps, zero-shot class maps, virtual multiplex marker maps, or predicted spatial expression. Models run on your own GPU server; this page never sees your images.

      Connect a backend

      GitHub Pages only serves this page. The models run in the small Python server in backend/, on whichever machine has the GPU.

      Local server: http://127.0.0.1:8000. Remote GPU: use an HTTPS tunnel URL — browsers block plain-HTTP calls from an HTTPS page except to localhost.
      Sent with each job so the server can download gated weights you have access to. Kept for this tab only. Logging in on the server (hf auth login) avoids this.

      Server status

      Connect to see GPU, packages and which models are ready.

      Start the backend

      1. On the GPU machine: cd backend, then pip install -r requirements.txt and install TRIDENT as described in that file.
      2. Copy config.example.yaml to config.yaml. Add this page's origin, a portal key, your slide folders and the GigaTIME / HEX / STPath clones.
      3. Run python -m uvicorn server:app --host 127.0.0.1 --port 8000.
      4. Remote machine? Forward the port over SSH (ssh -L 8000:127.0.0.1:8000 gpu-node) and keep the URL as 127.0.0.1, or put it behind an HTTPS tunnel.
      5. Gated models: request access on each Hugging Face model page first, then log in on the server.
